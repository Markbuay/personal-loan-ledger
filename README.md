# บัญชีเงินกู้ส่วนตัว

รุ่นนี้เก็บข้อมูลบนคอมเครื่องนี้ ใช้งานผ่านเบราว์เซอร์ และมีบัญชีเจ้าของเพียงคนเดียว การเชื่อม iPhone เป็นขั้นถัดไปตามที่ตกลง

## เปิดใช้งาน

1. ดับเบิลคลิก `เปิดแอป.cmd` จะเปิด http://127.0.0.1:4310
2. ครั้งแรกกรอกอีเมลและตั้งรหัสผ่านของคุณเอง
3. เก็บรหัสกู้คืนที่แอปแสดงไว้ในที่ปลอดภัย ใช้ตั้งรหัสผ่านใหม่ได้หากลืมรหัสผ่าน
4. เพิ่มผู้กู้ แล้วเพิ่มรายการกู้ เลือกหนี้เดิมเมื่อใส่ยอดยกมา หรือเลือกกู้ใหม่สำหรับการปล่อยกู้ใหม่

ข้อมูลไม่มีรายการตัวอย่างของบุคคลอื่น หลังทดสอบจะส่งมอบฐานข้อมูลเริ่มต้นว่างให้คุณใส่ข้อมูลจริง

## งานประจำ

- รับชำระโดยกรอกเงินที่รับจริง แยกคืนต้นกับชำระดอก ยอดทั้งสองส่วนต้องรวมเท่ากับเงินที่รับ
- หนี้เดิมใส่ต้นคงเหลือ ดอกค้างถึงวันเริ่มนับยอด วันเริ่มนับยอดและวันตัดรอบถัดไป ประวัติก่อนหน้านั้นที่ไม่มีข้อมูลแสดงว่ายังไม่ทราบ
- จ่ายเฉพาะดอกได้ การคืนต้นกลางงวดลดดอกในงวดถัดไป
- ปิดหนี้แสดงดอกตามวันจริงโดยใช้ฐานต้นตอนเริ่มรอบ ให้ตรวจยอดก่อนบันทึก
- รายการผิดใช้ยกเลิกพร้อมเหตุผลแล้วลงใหม่ เพื่อเก็บประวัติเดิม
- ติดตามการชำระ เปิดข้อความ ตรวจและคัดลอกไปส่งในบัญชี LINE/Facebook ส่วนตัว จากนั้นกลับมากดยืนยันส่งแล้ว
- หน้าสำรองข้อมูลดาวน์โหลด JSON พร้อมประวัติและหลักฐาน รวมถึง CSV สำหรับเปิดใน Excel เก็บไฟล์สำรองไว้คนละที่กับฐานข้อมูล

## ที่เก็บข้อมูล

ฐานข้อมูลและไฟล์หลักฐานอยู่ใน `.data/` ภายในโฟลเดอร์นี้ ไม่เก็บไว้ในโฟลเดอร์สกิล และไม่ส่งขึ้น Supabase หรือคลาวด์ สามารถสำรองทั้งโฟลเดอร์ `.data/` ได้เมื่อหยุดแอปแล้ว ไฟล์สำรองมีข้อมูลผู้กู้ ควรเก็บในที่ที่คุณเข้าถึงได้คนเดียว

ดับเบิลคลิก `หยุดแอป.cmd` เพื่อหยุดเซิร์ฟเวอร์ที่เปิดจากไฟล์เปิดแอป การปิดแท็บเบราว์เซอร์อย่างเดียวไม่ได้หยุดเซิร์ฟเวอร์

## การเตือนและกู้รหัสผ่าน

รายการเตือนก่อนวันนัด 1 วันและวันนัดแสดงในแอป เวลาเตือนคือ 13:00 น. ตามเวลาไทย การแจ้งเตือนเบราว์เซอร์ต้องได้รับอนุญาตและเปิดแอป/เครื่องไว้ รุ่นนี้ยังไม่ได้เชื่อม Push บน iPhone

ลืมรหัสผ่านใช้รหัสกู้คืนที่ได้ตอนสร้างบัญชี หากต้องการลิงก์กู้คืนทางอีเมล ให้ตั้งค่า SMTP ใน `.env` จาก `.env.example` แล้วเริ่มเซิร์ฟเวอร์ใหม่ อีเมลมีบทบาทเป็นชื่อบัญชีและปลายทางกู้คืน ไม่ได้บันทึกข้อมูลเงินกู้ขึ้นอีเมล แอปต้องแจ้งข้อผิดพลาดจริงเมื่อยังไม่ได้ตั้งค่า SMTP

## สำหรับพัฒนาต่อ

ต้องมี Node.js 24 ขึ้นไป แพ็กเกจล็อกเวอร์ชันไว้ใน package-lock.json

```powershell
npm.cmd install
npm.cmd test
npm.cmd run build
npm.cmd start
```

สาขารวมงานคือ `integration/loan-app` งานแยกเก็บใน `.scratch/loan-app/` ข้อกำหนดอยู่ใน APP-SPEC.md และคำศัพท์ใน GLOSSARY.md ไม่มีการแก้สกิลต้นฉบับ
