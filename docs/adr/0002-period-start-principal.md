# ใช้ฐานเงินต้นตอนเริ่มงวด

เจ้าของเลือกให้การคืนต้นระหว่างรอบลดดอกของรอบถัดไป ส่วนรอบที่เริ่มแล้วคงฐานเงินต้นตอนเริ่มงวด แม้ปิดหนี้ก่อนสิ้นรอบหลังเคยคืนต้นบางส่วนก็ใช้ฐานต้นดังกล่าวคูณสัดส่วนวันจริง การคำนวณจึงต้องเก็บหรือสร้างฐานต้นตามวันเริ่มงวด ไม่ใช้ยอดต้นคงเหลือ ณ วันนี้แทนฐานคิดดอกทุกกรณี เพื่อให้ยอดตรงกับข้อตกลงและตรวจย้อนหลังได้
