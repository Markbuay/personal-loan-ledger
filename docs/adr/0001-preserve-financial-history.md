# เก็บรายการเดิมเมื่อแก้ยอดย้อนหลัง

เจ้าของยืนยันให้แก้รายการรับชำระผิดด้วยการยกเลิกรายการเดิมพร้อมเหตุผล แล้วบันทึกรายการใหม่ แทนการเขียนทับหรือลบประวัติ เพื่อให้ตรวจสอบที่มาของยอดเงินได้ การแก้เงื่อนไขดอกมีงวดที่เริ่มใช้ ส่วนการแก้ยอดย้อนหลังมีรายการปรับปรุงพร้อมเหตุผล ดังนั้นการคำนวณยอดต้องคำนึงถึงสถานะรายการและวันที่มีผล และแสดงประวัติเดิมให้ตรวจย้อนหลังได้
